# Repository instructions

Keep `README.md` and `README.ja.md` minimal. In implementation PRs, document behavior, mechanisms, and design rationale in code and code comments instead of adding new explanatory prose to the READMEs.

If an implementation change makes existing README text inaccurate, correct or remove it. As a rule, an implementation PR's net README line count should not increase: corrections are typically neutral, while removals reduce it.

This constraint does not apply under `docs/`. Put explanations explicitly requested in review there.

Read [`.agents/skills/dotfiles/pr.md`](.agents/skills/dotfiles/pr.md) for repository-specific editing requirements.

This agent instruction file intentionally has no `.ja.md` translation.
